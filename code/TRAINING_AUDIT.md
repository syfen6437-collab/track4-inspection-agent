# 训练数据审计与提交检查

这些检查不调用模型、不占用 GPU，不更改训练标签、人工审核记录或正式
`result/result.json`。审计报告只写入 `runs/`，不属于可上传的预测结果。

## 训练图片审计

在工程根目录运行：

```powershell
.\.venv\Scripts\python.exe -u -X utf8 code\audit_training_data.py `
  --output runs\training_audit_20261012\report.json
```

程序只读取训练清单中列出的图片，不读取初赛测试集。它检查：

- 图片能否完整解码，路径是否位于 `data/raw/`；
- 文件 SHA-256 是否重复；
- 按 EXIF 方向修正并转换为 RGB 后，完整像素及尺寸是否相同；
- 相同图片是否具有不同类别、病害标签、评分或描述；
- 整桥留出后，是否仍有相同像素的图片留在拟合数据中；
- 每个标签的样本数、桥梁分布、场景分布、评分分布和空描述数量。

像素哈希使用完整分辨率，不用缩略图或相似度分数判定重复，因此同一图片
即使文件格式不同也能被识别。相似但不完全相同的连续帧不会被它认定为重复；
这不是完整的近重复或场景相关性检查。

`file_duplicate_groups` 和 `pixel_duplicate_groups` 分别记录文件与像素重复组。
冲突只被报告，不会被自动删除或“纠正”。例如同一图片的“完好”和“裂缝”标签
不同，需要追溯原始训练标注，不能仅因多数票或某个模型预测就覆盖标签。

`folds` 中的 `evaluated_content_overlap` 检查实际评测样本与拟合样本的内容
交叉；`all_excluded_content_overlap` 还检查整座被留出的桥及选中的轨道样本。
出现交叉时，本地评测可能存在泄漏，应先修正划分再比较策略，不将相关指标
当作独立留出证据。

报告中保留图片路径、标签和哈希，方便定位训练难例。缺失图片或解码错误
在 `image_errors` 中。审计需要逐张解码，耗时高于只检查文件名；同一路径的
报告不允许直接覆盖，重新审计请使用新的 `--output`。

## 正式结果严格校验

```powershell
.\.venv\Scripts\python.exe -u -X utf8 code\run_pipeline.py validate `
  --report runs\training_audit_20261012\baseline_validation.json
```

校验不仅检查数量与七字段，还要求每个字段是字符串，病害标签属于对应
类别，评分为空或字符串 `1` 至 `5`，并按文件名核对原输入的类别、桥名和
病害位置。数字型 `2` 不会被当成字符串 `"2"` 自动接受。

重复文件名、重复 JSON 键、`NaN`、`Infinity`、非 UTF-8 内容和解释性附加
文本均会被拒绝。UTF-8 BOM 为兼容已有文件而保留支持。失败时写出诊断报告，
不自动修补预测，也不改写原始结果。

## 2026-10-12 实际训练审计

本次完整报告保存于 `runs/training_audit_20261012/report.json`，检查了全部
3,402 条去重标注对应的训练图片：

| 项目 | 实测数量 |
| --- | ---: |
| 可完整解码图片 | 3,402 |
| 缺失或解码错误 | 0 |
| 不同完整像素内容 | 3,178 |
| 文件及像素重复组 | 各 190 |
| 重复组内图片条目 | 414 |
| 病害标签冲突组 / 涉及条目 | 19 / 68 |
| 评分冲突组 | 15 |
| 两个留出折的已评测内容交叉 | 均为 0 |
| 两个留出折的全部排除内容交叉 | 均为 0 |

19 组标签冲突都在桥梁：东溪河特大桥 15 组，青树湾1号大桥 4 组。
例子包括完全相同内容的 `19号墩支座.JPG` 与 `19号墩支座_2.JPG`，原始标注
分别为“完好”和“锈水流痕”；另一组 17 个相同梁底图片条目具有“粉红色色斑”、
“粉红色+渗水”等不同标签。抽查原始 `训练集/汇总数据.json` 确认这些差异
已在源标注中存在，不是本次预处理或模型自动改写造成的。

青树湾的四组冲突是左右幅文件共用航拍图片，一侧标“完好”，另一侧标
“沥青摊铺接缝”。这种情况可能对应同图不同目标区域；没有区域标注时，不能
仅凭图片像素相同就判断哪条标注错误。报告把它们列为复核项，不统一标签，
不删除训练记录，也不按文件名写入任何测试答案。

两折没有完全相同内容的拟合/评测交叉，只排除了这一类泄漏；相邻帧、相似
场景和原始标注含糊仍是残余风险。190 组重复也意味着 3,402 条记录不等于
3,402 个独立视觉样本。后续监督训练需单独验证重复组权重和冲突处理策略，
不能把未经验证的清洗直接用于正式结果。
