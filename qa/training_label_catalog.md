# 训练集标签目录与人工核对参考

本目录依据公开训练集的 3,402 条去重标注汇总：桥梁 2,602 条，轨道 800 条。括号内为该标签训练样本数。它反映的是数据集实际标注习惯，不是规范病害术语表；同一现象可能被写成多个近义标签，少数描述也带有待核实措辞。

## 如何看真实样例

打开本地审核页 `http://127.0.0.1:8765/`，在“问题类型”选桥梁或轨道，再从“训练标签”下拉框选择标签并应用筛选。中间显示真实训练图片，右侧有原始标签、原始描述和评分。判断时以图片可见证据为主；看不清就标“需复核”，不要根据文件名或模型猜。

## 常见视觉概念

| 概念 | 通常可见的样子 | 容易混淆之处 |
|---|---|---|
| 修补痕/已处治病害 | 颜色、材质或纹理与周围不同的补丁；常见规则矩形、封孔、修补带 | 规则模板孔、施工封堵不一定是新病害；“修补痕”不表示当前仍在发展 |
| 剥落 | 混凝土局部脱落、边角缺损，可能露出粗骨料或钢筋 | 表面污渍、模板边缘、阴影不是剥落 |
| 裂缝 | 混凝土表面连续细线或开口，常需近距离观察走向和宽度 | 构造缝、拼接缝、模板线、阴影可能像裂缝 |
| 渗水/泛碱 | 潮湿痕、深色水迹、白色结晶/析出物，常沿接缝或排水路径分布 | 污染、雨痕、材料色差需结合位置判断；泛碱未必仍在渗水 |
| 锈蚀/锈水 | 金属红褐色锈斑，或混凝土表面从金属件/孔洞向下的黄褐色流痕 | 锈水流痕不能单凭颜色确认内部钢筋锈蚀；可能是外露金属或排水污染 |
| 蜂窝/麻面/气泡 | 混凝土表面孔洞、凹坑、粗糙不密实区域 | 小气孔或模板纹理不一定达到病害程度 |
| 苔藓/植被 | 绿色藻苔、植物在结构表面或邻近构件生长 | 绿色涂层、反光色偏；植被本身与结构损伤要分开描述 |
| 沥青摊铺接缝/伸缩缝 | 桥面纵横向接缝、伸缩装置附近的材料边界或磨耗 | 接缝是构造/施工特征；只有开裂、破损、松散、异常渗水等证据才说明病害 |

## 需要人工特别注意的数据问题

- 桥梁“已处治病害（修补）”“修补痕”“修补痕迹”相近但并不完全相同；规则施工封孔不一定是活动病害。
- “锈蚀/碳化”把不同机理合在一个标签里；只凭一张照片常无法确认碳化深度或内部钢筋状态。
- 同一类水迹在训练集中会出现“渗水/泛碱”“接缝渗水”等近义标签，个别描述还写“无渗漏”。
- “完好”占桥梁标签约 73%；它通常只说明当前图像视野内未标病害，不表示整座桥安全。
- 轨道组合标签样本较少，不能因其少见就认为图片里没有第二种病害。
